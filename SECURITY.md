# Security

Assistant listens to your microphone, runs Claude Code with permission to edit files and run commands in the folders you give it, and serves a local panel and API on `127.0.0.1:4780`. A bug in any of these can expose someone's work or let something act on their Mac, so please report it privately.

**How:** open a [private security advisory](https://github.com/ciro-maciel/voice-assistant/security/advisories/new) on this repository. Please don't open a public issue for it.

**What helps:** the macOS version, the steps, and what was exposed or done without being asked. Never attach recordings of your voice or transcripts with private content: describe them.

You will get an answer within a week. Once a fix ships, the advisory is published with credit to you, unless you'd rather stay anonymous.

Supported: the latest release only.
